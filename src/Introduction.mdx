# HexGlass

Hex-Tech's React component library, built on **Base UI** (behavior & accessibility)
and **Tailwind CSS v4** (styling), with a visual signature: **professional liquid glass**.

## Glass principles

- **Panes, not frost**: surfaces blur what is behind them only lightly, and their rim bends it like the edge of
  a thick piece of glass (in Chromium browsers).
- **Readability first**: in the dark theme, or over a `Backdrop` image, each pane evens out what is behind it,
  darker under white text and lighter under dark text, so text holds over a photo. A plain light page keeps
  lightly veiled panes.
- **Surfaces**:
  - `glass-thin`: navigation, toolbars, tabs (little text);
  - `glass`: cards, panels;
  - `glass-strong`: menus, popovers, tooltips, toasts, with more frost;
  - `glass-dialog`: dialogs and sheets, with the strongest frost;
  - `glass-field`: form fields;
  - `glass-stained`: primary and danger buttons, a dense colored pane with white text;
  - `glass-tint`: checked switches, checkboxes and radios, slider and progress bars.
- **A real material**: lit edge at the top left, a very fine grain, an inner glow along the rim. There is no
  glow around elements.
- **Hover and selection**: _inside_ a glass surface (rows, list items, ghost button), use a light
  `tint-hover` / `tint-active` veil. _On_ a glass element (secondary button), use `glass-hover`.
  A selected element sitting on glass (tab indicator) is always lighter than its container.
- **Accessible fallbacks**: surfaces become opaque automatically when the browser does not support `backdrop-filter`,
  when the user turns on "Reduce transparency", or in high-contrast mode.

## Background

The `Backdrop` component provides the background that gives glass its meaning. Change it from the **Background**
tool in the toolbar to check that a component stays readable on each variant, including with no background.

## Themes

Add the `dark` class (or `data-theme="dark"`) to `<html>`. Use the Storybook toolbar to switch.

## Customization

The palette is indigo (`#4f46e5`) on neutral grays. The background glows combine indigo, cyan and light violet.

Every color is an overridable `--hx-*` CSS variable:

```css
:root {
  --hx-accent: #a5b4fc;
  --hx-liquid-blur: 12px;
}
```
